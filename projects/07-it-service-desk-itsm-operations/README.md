# IT Service Desk & ITSM Operations Lab

![Status](https://img.shields.io/badge/Type-Personal%20Lab-blue)
![Owner](https://img.shields.io/badge/Owner-Muhammad%20Huzefa-purple)

## Overview

An enterprise-style service desk project based on the incident and request workflows used in IT operations.

**Primary skills:** ManageEngine ServiceDesk, ITIL, Incident, Request, SLA, Knowledge Base

## Service Categories

- Account & access
- Microsoft 365
- Hardware
- Software
- Network
- VPN
- Security
- Mobile/Apple
- Procurement

## Workflow

```
Ticket → Categorize → Prioritize → Diagnose → Resolve
                                      |
                                      v
                                 Escalate
                                      |
                                      v
                              User Confirmation
                                      |
                                      v
                                    Close
```

## Example SLA Model

| Priority | Example | Target |
|---|---|---|
| P1 | Major service outage | Immediate |
| P2 | Multiple-user impact | High |
| P3 | Individual business-impacting issue | Normal |
| P4 | Standard request | Planned |

Targets shown here are illustrative lab values.

## Knowledge Articles

Create KB articles for password reset, VPN troubleshooting, Outlook issues, device onboarding, BitLocker recovery and common Windows incidents.

## Metrics

Track first response, resolution time, reopen rate, backlog and category trends.


## Evidence Standard

Implementation evidence will be added as the lab is completed. Screenshots, diagrams, scripts and test results should represent actual work performed in the personal lab.
