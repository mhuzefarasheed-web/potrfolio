PowerShell Endpoint Inventory & Audit Automation

Project Overview

The project targets repeatable collection of hardware, operating-system, network and security data that can support helpdesk and asset-management workflows.

CorePowerShell
CollectionWMI / CIM
OutputCSV reports
SecurityRead-only collection where possible; no secrets
DeliverablesGet-EndpointInventory.ps1 · Export-EndpointAudit.ps1

Project Scope

  • Computer name and serial number
  • Manufacturer and model
  • CPU and RAM
  • RAM slot information
  • Disk type and capacity
  • Windows version
  • Wi-Fi adapter and MAC
  • IP configuration
  • Logged-in user
  • BitLocker status
  • CSV reporting and troubleshooting notes
