## Overview

A practical security-hardening and monitoring project for Windows endpoints and servers.

**Primary skills:** Windows Security, GPO, BitLocker, Defender, Event Logs, Monitoring

## Hardening Areas

- Least privilege
- Local administrator control
- Password/account policies
- Windows Defender configuration
- Firewall
- BitLocker
- Secure RDP practices
- Audit policies
- Event log review
- Patch/update hygiene

## Monitoring Scenarios

Simulate and document:
- Failed logons
- Account lockouts
- Service failure
- Disk-space alerts
- Endpoint offline state
- Repeated authentication failures

## Response Workflow

```
Alert → Validate → Scope → Contain → Remediate → Document
```
