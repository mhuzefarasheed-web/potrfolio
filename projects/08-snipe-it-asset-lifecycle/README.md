## Overview

A complete asset lifecycle project covering procurement, tagging, assignment, audit and retirement.

**Primary skills:** Snipe-IT, Asset Lifecycle, Procurement, Inventory, Audit

## Asset Lifecycle

```
Request → Approve → Procure → Receive → Tag → Assign
                                      |
                                      v
                              Support / Audit
                                      |
                                      v
                              Return / Repair
                                      |
                                      v
                                Retire / Dispose
```

## Asset Register

Track:
- Asset tag
- Serial number
- Model
- User
- Department
- Location
- Purchase date
- Warranty
- Status
- Accessories
- Software/licenses

## Example Controls

- Unique asset tags
- Check-in/check-out
- User acknowledgment
- Quarterly inventory audit
- Offboarding checklist
- Disposal record

All sample values are fictional.
