# Module 03 — IT Asset Management with Snipe-IT

## Purpose

This module demonstrates a controlled IT asset lifecycle using Snipe-IT as the asset-management platform.

## Asset Categories

- Laptop
- Desktop
- Monitor
- Docking station
- Keyboard
- Mouse
- Headset
- Mobile device
- Network equipment
- Software license

## Lifecycle

```
Procure
  |
  v
Receive
  |
  v
Inventory
  |
  v
Configure
  |
  v
Assign
  |
  v
Support / Audit
  |
  v
Return
  |
  v
Retire / Dispose
```

## Example Asset Record

| Field | Example |
|---|---|
| Asset Tag | HZ-LT-0001 |
| Type | Laptop |
| Department | IT |
| Status | Assigned |
| Assigned To | Lab User |
| Location | Karachi Lab |
| Warranty | Documented separately |
| Serial | Lab test value |

All values used in this personal lab are fictional/test values.

## Learning Goals

- Asset inventory
- User assignment
- Asset check-in/check-out
- License tracking
- Lifecycle management
- Audit readiness
- Inventory reporting
