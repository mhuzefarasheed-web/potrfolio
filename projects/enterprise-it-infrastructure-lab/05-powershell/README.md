# Module 05 — PowerShell Automation

## Purpose

PowerShell is used to reduce repetitive administrative work and create repeatable IT operations.

## Planned Scripts

- Computer inventory collection
- Windows system information
- Network adapter information
- IP/DNS configuration checks
- Disk information
- Service status
- Local administrator audit
- Active Directory user reporting
- Basic endpoint health checks

## Script Design Principles

Each script should:

1. Have a clear purpose
2. Validate inputs
3. Handle errors
4. Produce readable output
5. Avoid exposing credentials or secrets
6. Include comments and usage instructions
7. Be tested in a lab before production use

## Security

Scripts will never contain:

- Passwords
- API keys
- Tokens
- Production credentials
- Personal employee information
