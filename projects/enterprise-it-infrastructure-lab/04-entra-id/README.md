# Module 04 — Microsoft Entra ID & Identity Management

## Purpose

This module documents cloud identity concepts relevant to Microsoft 365 administration.

## Planned Scope

- Users
- Groups
- Administrative roles
- Role-based access control
- Authentication methods
- Microsoft 365 identity
- Conditional access concepts
- Least privilege
- Identity lifecycle

## Example Role Model

```
Global / Tenant Administration
          |
     IT Administration
          |
     Helpdesk Support
          |
       End User
```

The actual implementation will use the minimum permissions required for each task.

## Security Principles

- Least privilege
- Separation of duties
- Strong authentication
- Administrative account separation
- Regular access review
- Controlled role assignment

## Important Note

This documentation distinguishes between features available in the selected Microsoft licensing tier and features requiring additional licensing. No paid feature will be represented as implemented unless it was actually available in the lab environment.
