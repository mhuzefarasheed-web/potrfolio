Microsoft 365 & Exchange Online Migration Lab

Project Overview

The project documents the migration lifecycle from mailbox inventory and tenant preparation through DNS cutover, pilot validation, Outlook reconnection, PST checking and legacy-service decommissioning.

SourceHosted / cPanel mail
TargetMicrosoft 365 / Exchange Online
ValidationMail flow · Outlook · PST · DNS
MethodPilot → Cutover → Verify
UsePersonal migration lab

Project Scope

  • Tenant, accepted-domain and mailbox preparation
  • MX cutover planning and DNS validation
  • SPF, DKIM and DMARC validation concepts
  • Exchange Online mailbox creation
  • Outlook profile and Autodiscover considerations
  • PST export/import validation
  • Shared mailbox and delegation concepts
  • Rollback checklist
  • Post-migration mail-flow verification
