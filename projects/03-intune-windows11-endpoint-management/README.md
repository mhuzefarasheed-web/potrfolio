# Microsoft Intune & Windows 11 Endpoint Management Lab

![Status](https://img.shields.io/badge/Type-Personal%20Lab-blue)
![Owner](https://img.shields.io/badge/Owner-Muhammad%20Huzefa-purple)

## Overview

A modern endpoint-management lab covering Windows 11 enrollment, configuration, compliance and security controls.

**Primary skills:** Microsoft Intune, Entra ID, Windows 11, Compliance, Configuration Profiles, BitLocker

## Scenario

Build a small managed Windows 11 fleet representing enterprise laptops.

## Lab Scope

- Entra ID device identity
- Windows enrollment
- Configuration profiles
- Compliance policies
- BitLocker policy concepts
- Windows Update management
- Security baselines
- Application deployment
- Device inventory
- Remote troubleshooting workflow

## Device Lifecycle

```
Procure → Enroll → Configure → Secure → Monitor → Support → Retire
```

## Example Policies

- Screen lock timeout
- Password requirements
- BitLocker enablement
- Microsoft Defender settings
- Windows Update deployment
- USB/removable-media controls
- Local administrator restrictions
