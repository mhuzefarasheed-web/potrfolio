Project Overview

The project uses fictional lab addressing to model separate IT, staff, voice, guest, server and CCTV/IoT networks. It also documents troubleshooting checks for common client and connectivity failures.

VLANs10 IT · 20 Staff · 30 Voice · 40 Guest · 50 Servers · 60 CCTV/IoT
AddressingFictional 10.10.x.0/24 lab subnets
ServicesDHCP · DNS
SecurityGuest isolation · Firewall rules
PlatformUDM Pro concepts

Project Scope

  • VLAN planning and logical segmentation
  • IP addressing and subnetting
  • DHCP scopes
  • DNS resolution
  • Inter-VLAN routing
  • Guest isolation
  • Server/client network separation
  • Firewall rule design
  • UDM Pro concepts
  • Troubleshooting with ping, nslookup and tracert
